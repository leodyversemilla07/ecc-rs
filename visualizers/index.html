Visualizers

Three instrument panels that show the mathematics behind this crate. Every number on these pages is computed the way the Rust computes it: the pages mirror the source line by line, and they show the branches where the crate panics just as faithfully as the branches where it returns a result.

how these pages stay honest

they mirror the source

The Rust snippets shown next to the animation are generated from the actual files in this repository by node visualizers/assets/sync-rs-source.mjs. They cannot drift silently.

they mirror the semantics

The JavaScript in visualizers/assets/ecc.js re-implements FiniteField, EllipticCurve and Ecdsa, including their assert!s. A failing assert becomes a visible "the program panics here".

they were checked against the crate

A parity harness compared the two implementations over more than 300,000 cases — every field operation for eleven primes, every point addition and doubling for five curves, 40 scalar multiplications each, and every key pair and nonce on the teaching curve — with zero differences.

run it locally

There is no build step. Open any page in a browser, or serve the folder:

python -m http.server --directory visualizers
